# Resizer Pro 🖼️

Um redimensionador de imagens ultra-rápido e profissional que roda diretamente no navegador, sem necessidade de backend.

## ✨ Funcionalidades

- **Drag & Drop** — Arraste e solte imagens diretamente na interface
- **Controle de Dimensões** — Defina largura e altura exatas em pixels
- **Proporção Bloqueada** — Mantém a proporção original automaticamente
- **Controle de Qualidade** — Slider de qualidade de 1% a 100%
- **Preview em Tempo Real** — Visualize a imagem antes de baixar
- **Interface Moderna** — Design glassmorphism com animações suaves
- **100% Client-Side** — Nenhum dado é enviado para servidores

## 🚀 Como Usar

1. Abra o arquivo `index.html` no seu navegador
2. Arraste uma imagem ou clique para selecionar
3. Ajuste as dimensões desejadas
4. Regule a qualidade da imagem
5. Clique em **"Baixar Imagem Redimensionada"**

## 🛠️ Tecnologias

- **HTML5 Canvas** — Para redimensionamento de imagens
- **Tailwind CSS** — Framework utilitário para estilização
- **Vanilla JavaScript** — Sem dependências externas
- **Google Fonts (Outfit)** — Tipografia moderna
